Ответьте своими словами.

1. Для чего нужны понятные имена переменных?    # Чтобы не хуесосили другие программисты
2. Какой стиль именования обычно используется для переменных и функций Python?   # PEP 8
3. Как записывают имена констант по соглашениям PEP 8?   # Большими буквами
4. Какое имя лучше: `x` или `user_age`? Почему?  # 'user_age', чтобы другие программисты понимали код
5. Что не так с именем `productName` в обычном Python-коде?  # Его надо написать так: 'PRODUCT_NAME'
6. Можно ли назвать переменную `class`? Почему?  # Нет, так как в Python есть такая функция с данным именем
7. Почему нежелательно использовать `a`, `b`, `c`, если переменные хранят цену, количество и итог?   # Чтобы не хуесосили другие программисты
8. Нужно ли менять имя переменной во всех местах программы после переименования? # Да
9. Исправьте строку: `total_price = price * count`
10. Какое имя лучше для количества попыток входа: `n`, `tries`, `attempt_count`? Почему? # `attempt_count`, так как она более всего подробная
