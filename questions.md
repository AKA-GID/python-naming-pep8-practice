# Вопросы по именованию и PEP 8

Ответьте своими словами.

1. Для чего нужны понятные имена переменных? 
2. Какой стиль именования обычно используется для переменных и функций Python?
3. Как записывают имена констант по соглашениям PEP 8?
4. Какое имя лучше: `x` или `user_age`? Почему?
5. Что не так с именем `productName` в обычном Python-коде?
6. Можно ли назвать переменную `class`? Почему?
7. Почему нежелательно использовать `a`, `b`, `c`, если переменные хранят цену, количество и итог?
8. Нужно ли менять имя переменной во всех местах программы после переименования?
9. Исправьте строку: `totalPrice=price*count`
10. Какое имя лучше для количества попыток входа: `n`, `tries`, `attempt_count`? Почему?
11. Что означает правило «одна переменная — одна понятная роль»?
12. В чём разница между `user_name` и `USER_NAME` с точки зрения принятого стиля?

## Мини-челлендж
Придумайте имена для переменных, хранящих:
- температуру воздуха в градусах Цельсия;
- количество непрочитанных сообщений;
- цену одного билета;
- результат проверки пароля;
- максимальное число попыток входа.
