# Практика: имена переменных и PEP 8

**Время:** 80 минут · **Уровень:** начинающий

## Цель
Научиться выбирать понятные имена переменных и оформлять код в едином стиле, не меняя его поведение.

## Порядок работы
1. Откройте проект в PyCharm.
2. Выполняйте файлы из папки `tasks` по порядку.
3. Переименовывайте переменные во всех местах использования.
4. Исправляйте оформление по PEP 8.
5. Не меняйте формулы, условия и логику программы.
6. Ответьте на вопросы из `questions.md`.
